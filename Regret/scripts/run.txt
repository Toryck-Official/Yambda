1. 数据切分：主线 time_hour B_rev
-------------------------------

说明：
原始 timestamp 单位为 5 秒。
相邻事件间隔 > 720 ticks，即 > 3600 秒，切成新 session。
session 内连续同 item 事件聚合成一个 RL step。
step_time 取连续同 item run 的最后一个原始事件 timestamp。
公式 8 的 Delta_tr 使用 time_hour：
Delta_tr = (current_step_time - failed_step_time) * 5 / 3600。

为避免混入刚才可能留下的半成品，当前建议使用新路径 main_v1_data_timehour_r1。

启动：
screen -dmS split_timehour bash -lc 'cd /root/autodl-tmp/0408Yambda/Regret && FORCE_SPLIT=1 OUT_ROOT=artifacts/transitions/main_v1_data_timehour_r1 MAIN_ID=main_v1_timehour_r1 ./scripts/01_split_data.sh'

看进度：
screen -r split_timehour

如果 screen 已退出，看日志：
tail -f /root/autodl-tmp/0408Yambda/Regret/artifacts/logs/main_v1_timehour_r1_split.log

切分完成后检查 meta：
sed -n '1,160p' /root/autodl-tmp/0408Yambda/Regret/artifacts/transitions/main_v1_data_timehour_r1/split.meta.json

3. 主线策略训练：固定权重 + RAPI + current RRCA
---------------------------------------------

含义：
omega/lambda 固定为 1。
RRCA_APPLY_TO=effective_reward。
RRCA_CALLBACK_TARGET=current，即只修正当前五元组 reward。
TRAIN_USE_RAPI=1，即训练 rollout 中使用失败记忆池。
GATE_REVISION_BY_HISTORY=1，即 unlike 必须有同 item 历史 like，undislike 必须有同 item 历史 dislike，才算有效撤销信号。

启动，使用默认 current simulator：
screen -dmS policy_main bash -lc 'cd /root/autodl-tmp/0408Yambda/Regret && TRANSITION_ROOT=artifacts/transitions/main_v1_data_timehour_r1 MAIN_ID=main_v1_timehour_r1 POLICY_SAVE_PREFIX=artifacts/models/policy_hsac_main_timehour_r1 ./scripts/03_train_policy.sh'

如果使用本轮重训 simulator：
screen -dmS policy_main bash -lc 'cd /root/autodl-tmp/0408Yambda/Regret && TRANSITION_ROOT=artifacts/transitions/main_v1_data_timehour_r1 SIMULATOR_CHECKPOINT=artifacts/user_response/main_v1_timehour_r1_sim/regret_user_response.pt MAIN_ID=main_v1_timehour_r1 POLICY_SAVE_PREFIX=artifacts/models/policy_hsac_main_timehour_r1 ./scripts/03_train_policy.sh'

看进度：

日志：
tail -f /root/autodl-tmp/0408Yambda/Regret/artifacts/logs/main_v1_timehour_r1_policy_train.log
