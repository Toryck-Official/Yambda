# Phase 1 Gates

本目录只用于：

1. Gate 1 metadata proxy leave-one-out reliability；
2. Gate 2 full explicit item semantic collision 与 exact identity 设计。

禁止在本目录中训练 SNMPP/HPN，禁止生成最终 canonical train/validation/test。

目录：

- `configs/`：冻结 Gate 参数；
- `scripts/`：可复现实现；
- `artifacts/`：机器可读正式结果；
- `work/`：可重建中间数据；
- `logs/`：screen 日志；
- `reports/`：面向汇报的 Gate 结论；
- `tests/`：小型合成和守恒测试。
